# 릴리스 블로커

`docs/mvp-status.md`의 남은 일 목록이 정본이다. 이 문서는 그중 **파일럿을 시작하기
전에 반드시 닫아야 하는 것**만 추려 체크리스트로 둔다.

코드 검증이 통과하는 것과 사람이 검수한 것은 다르다.
`npm run validate`는 규칙을 지켰는지만 본다. 금융 논리가 맞는지는 보지 못한다.

## 시작 전 확인

- [ ] 읽기 32편 본문·문항 전수 검수 (화면에서, 소스 파일이 아니라)
- [ ] 이번에 넣은 수치 확인. 특히 `cx-core-cpi`의 물가 수치를 유지할지 판단
- [ ] 브리핑 10편
- [ ] 개념 구분 29개, O/X 30개
- [ ] 한국은행 정의문 94개: 표제어를 가린 문장이 자연스럽게 읽히는지
- [ ] 리포트 원고 27개
- [ ] 한국은행 『경제금융용어 700선』 활용 조건 확인, 출처 표기 위치 점검
- [ ] `/api/health`가 200 (하나라도 빠지면 503과 누락 목록이 나온다)
- [ ] 토큰 없이 `/api/export`, `/api/cron-nudge` 호출 시 404
- [ ] iPhone Safari: 홈 화면 추가 → 오프라인 실행 → 알림 수신
- [ ] Android Chrome: 설치 → 알림 수신
- [ ] 사파리 프라이빗 모드에서 저장 실패 안내가 뜨고 학습이 끝까지 되는지
- [ ] KST 자정 경계 전후 복습 큐
- [ ] 오프라인에서 세션을 끝내고 온라인 복귀 시 완료 상태가 재전송되는지
- [ ] 데이터 보관 종료일을 정해 두기

## 시작 전에 닫지 않아도 되는 것

- Report 27개의 구분·O/X 문항 (현재 0개). 뜻/떠올리기로 학습은 된다
- 학습 후보 221 → 400 → 800 확장
- 다중 기기 연속성 (계정이 필요하다)

이유는 `docs/mvp-status.md`의 P4에 적었다. 파일럿 결과가 YES일 때만 손댄다.
