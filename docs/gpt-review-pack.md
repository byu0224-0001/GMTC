## 0. 이번 리뷰에서 봐 달라는 것

제품 정의는 고정입니다.

> 출퇴근 5–10분에, 경제·투자 정보가 덜 막히게 한다. 암기장도 뉴스 앱도 아니다.

페르소나: 20–30대 직장인, 입문~초중급. 뉴스·리포트·은행 앱을 보다가 용어에서 멈춘다.

North Star: 퀴즈 점수가 아니라 **앱 밖에서 같은 뉴스가 덜 막히는 것**.

이번엔 기능 아이디어를 더하지 마세요. 아래를 코드·카피 근거로 냉정히 답해 주세요.

1. **효용감**: 오늘 루프를 한 번 돌면 페르소나의 통증이 실제로 줄어드는가.
2. **E2E**: 홈 → 신규 학습 → 첫 회상 → 복습 → 브리핑 → 완료가 하나의 이야기인가, 퀴즈 조각의 나열인가.
3. **학습 효과**: 같은 정의를 다시 고르는 구조가 전이를 만드는가. 문제와 해설이 같은 층이면 학습이 아닌가.
4. **현재 수준에서의 최선**: 로그인 없음, RSS 미연결, 손글 브리핑 10편. 이 제약에서 파일럿을 10명에게 줄 수 있는가.
5. **카피**: 한국어 UX가 금융 서비스 신뢰 수준인가. AI가 “고쳤다”고 해서 통과시키지 말 것.

추측하지 말고 `gpt-pack.txt`와 이 문서를 근거로 지적하세요.

## 1. 냉정한 자체 판단 (PM / PD / CTO)

**완벽한가? 아니다.**  
**파일럿으로 줄 수 있는가? 조건부 예.**  
**페르소나 통증을 끝내는가? 아직 아니다. 입구만 있다.**

### PM

잘된 점

- JTBD가 좁다. “800선 암기”가 제품명이 아니다.
- 오늘 한 편이 개념 2–3개 + 브리핑으로 묶인다. Core100 전체를 매일 들이밀지 않는다.
- 계정이 없다. 설치 마찰이 낮다.
- 가짜 뉴스를 진짜처럼 보여 주지 않는다. 학습용이라고 밝힌다.

약한 점

- **효용감이 퀴즈 완료에 붙어 있다.** 사용자는 “맞혔다”를 느끼지만, 내일 뉴스 헤드라인을 읽을 수 있는지는 측정하지 않는다.
- Today가 **고정 합성 브리핑**이다. “최신 이슈” 약속과 어긋난다. RSS→픽→초안 파이프라인은 앱 밖에만 있다.
- 복습이 최근까지 SM-2로 수개월까지 밀렸다. 지금은 1–2일로 고정했다. 출퇴근 앱치곤 맞지만, “익숙해짐” 통계는 아직 조잡하다.
- 로그인·동기화 없음. 폰을 바꾸면 진도가 사라진다. 파일럿에는 맞다. 제품화에는 부채다.

### PD

잘된 점

- 탭 네 개(오늘 / 학습 / 실전 / 사전)는 한국 금융 앱처럼 짧고 자연스럽다.
- 세션은 카드 → 객관식 → 해설 → 관련 사슬. 출퇴근 한 손으로 가능하다.
- 완료 화면에 인과 사슬(`물가 상승 → … → 채권가격 하락`)이 있어, 단어 나열보다 한 장면으로 남는다.

약한 점

- **문제 문장이 정의 그대로**인 경우가 많다. “이 설명의 용어는?”이 아니라 정의 블록을 주고 고르게 한다. 인식(recognition)이지 인출(recall)이 약하다.
- 첫 회상에 `다음 설명에 맞는 용어를 고르세요`를 붙이던 것은 영어 UI 잔재였다. 지금은 설명문만 남긴다.
- 해설이 혼동 포인트로 바뀌었지만, 문장이 여전히 번역투인 경우가 있다. 예: 기대인플레이션.
- 보기 라벨이 `연방준비제도 / 연방준비은행(FRB) (FRS)`처럼 내부 별칭을 그대로 붙이던 버그가 있었다. `displayTitle`은 표제어+약어만 쓰도록 고쳤다.
- 브리핑 중간에 `나중에 이어가기`는 동사 활용이 어색했다. `나중에 이어서 하기`로 바꿨다.
- **실전 탭**에 짧은 연습·사고 틀·사실/전망 퀴즈가 섞여 있다. 오늘 루프의 연장인지, 별도 코스인지 사용자에게 안 읽힌다.

### CTO

스택: Vite + React 19 + TS, PWA, Vercel Hobby. 백엔드 없음.

잘된 점

- 학습 상태 `localStorage` (`voca:progress:v2`, schema 4). 서버 없이 파일럿이 돈다.
- 한은 원문은 `terms.json`에 두고, 학습 문장은 `coreCopy.ts`로 분리했다. 원문 재배포 위험을 화면에서 줄이려 한 설계다.
- GitHub `main` 푸시가 Vercel 프로덕션으로 붙었다.

약한 점

- PWA `sw.js`가 `/`와 `/assets/`를 캐시한다. 배포 직후 옛 카피·옛 복습 간격이 남을 수 있다. 캐시 이름을 `voca-shell-v5`로 올렸다.
- 퀴즈 오답 선택지가 분야 랜덤이라, 기준금리 보기에 연준이 나와 **구분 학습**이 아니라 **잡다한 객관식**이 된다.
- Editorial은 Python + GitHub Actions. 앱은 `today.json`의 `bf-cpi-rates`만 본다. 운영 루프가 닫히지 않았다.
- 공개 저장소에 `terms.json`(한은 문장)이 들어 있다. 라이선스 리스크.

### 학습 효과

지금 구조의 정직한 한계:

| 단계 | 의도 | 실제 |
| --- | --- | --- |
| 신규 | 한 줄 + 쉬운 설명 + 투자할 때 | 읽기. SRS 없음. 좋음. |
| 첫 회상 | 방금 본 정의를 고른다 | 너무 쉽다. 전이 약함. |
| 복습 | 같은 정의 또는 cloze/contrast | contrast는 손글 있는 용어만. 파일럿 상당수는 정의 재인. |
| 브리핑 | 장면 속에 용어를 넣는다 | 여기가 제품의 핵심이다. 손글 10편에 품질이 묶여 있다. |

**결론:** 브리핑이 좋으면 효용이 있다. 퀴즈만 반복하면 암기장에 가깝다. 파일럿 검증은 “퀴즈 정답률”이 아니라 “같은 뉴스를 다시 읽게 했을 때 막히는지”여야 한다.

## 5. 카피 상태 (2026-09-04 저녁)

고친 것 (화면에서 지적된 것 포함)

- `기대가 높다고 내일 CPI가 그 숫자로 나온다는 뜻은 아닙니다` → `가계나 시장이 예상하는 물가이지, 통계청이 발표하는 실제 소비자물가와는 다른 숫자입니다.`
- 첫 회상 꼬리 문장 `다음 설명에 맞는 용어를 고르세요` 삭제. 설명문만.
- `기준금리 = 주담대` / `바로 같아지지 않습니다` → 시차를 두고 따라간다는 설명.
- CPI 해설: 수준 vs 상승을 “다른 이야기”.
- `물가 · 개념 확인` 같은 내부 타입 노출 제거. 복습 캡션은 분야명만.
- `나중에 이어가기` → `나중에 이어서 하기`
- `원문을 옮기지 않았습니다` → `문장을 그대로 가져오지 않았습니다`
- 보기 제목: pairHeadwords 나열 금지.

남은 리스크

- `coreCopy.ts` 72개 본문, `briefings.ts` 10편, `reportLexicon`/`literacy` 장면 문장은 **원어민+금융 검수가 아직 통과가 아니다.**
- 정의 문장을 문제로 그대로 쓰는 패턴은 카피만이 아니라 **문항 설계** 문제다.

카피 원칙 (유지)

- `말` 금지. 용어/개념/표현.
- 버튼은 동사.
- 가격을 쓴다, 같은 말로, 확인된 층, 튜터 구어체 금지.
- 하단 탭 `오늘 학습 실전 사전`은 유지.

## 6. 파일럿 Go / No-Go 체크

Go에 가까운 것: 설치 가능, 오늘 루프가 있다, 한 편 인과가 보인다, 계정 없이 시험 가능.

No-Go에 가까운 것: 카피가 신뢰도를 깎는 문장이 남아 있으면 금융 학습 앱으로 못 준다. 최신 이슈가 안 바뀌면 “오늘”이 거짓 광고가 된다. 정의 재인 퀴즈만 반복되면 전이를 주장할 수 없다.

10명 파일럿을 한다면 물어야 할 것:

1. 오늘 세션 후, 같은 날 뉴스 헤드라인 하나를 주고 어디서 막혔는지.
2. 해설이 문제를 반복한다고 느꼈는지.
3. 5–10분이 맞는지, 브리핑이 긴지.
4. 내일 다시 열고 싶은지.

기능 추가(로그인, RSS 자동 발행, 그래프)는 이 네 질문이 긍정일 때.
