# 학습 기록 지표

홈과 상세 기록은 `src/lib/evidence.ts`의 `progressEvidence()`만 쓴다.
숫자는 모두 **고유 용어 수**다. 같은 말을 여러 번 봐도 1이다.

| 지표 | 계산 | 기존 사용자 |
| --- | --- | --- |
| 새로 만난 말 | 해당 기간이 `successDates[0]`인 카드 | 복원 가능 |
| 다시 본 말 | 이전에 배운 뒤 해당 기간 다시 맞힌 카드 | 복원 가능 |
| 익숙해진 말(기간) | `isFamiliar`이고 `familiarAtRecorded === true`이며 그 날이 기간 안 | **이번 배포 이후만** 정확 |
| 지금 익숙한 말 | `isFamiliar()` | 복원 가능. 시점은 모름 |
| 읽기 | 완료한 글 id 수 | 복원 가능 |
| 읽기에서 다시 만난 말 | 완료한 글 본문의 용어 중, 읽은 날보다 먼저 배운 고유 용어 | 완료 시각과 first seen이 있을 때만 |
| 헷갈리는 개념 | `lapses >= 2`이거나 contrast를 틀린 상태. 한 번 오답은 넣지 않음 | 반복 혼동만 |

소급하지 않는 것: `familiarAt`이 학습 순간에 찍히지 않은 카드는 ‘이번 주 익숙해진 말’에 넣지 않는다.
과거 익숙한 말은 ‘현재 익숙한 말 N개’로만 보여 준다.
