# Private Source Vault

증권사 PDF는 앱에 넣지 않습니다. 저작권상 복제·배포·전송이 금지된 자료가 많습니다.

권장 위치 (이 저장소 밖):

```text
~/VocaSourceVault/reports/
  semiconductor/
  auto/
  cosmetics/
  financial/
  governance/
  ai-infra/
```

여기 `private-source/` 폴더는 gitignore입니다. 실수로 PDF를 넣어도 커밋되지 않게 하기 위한 자리입니다.

앱에 올리는 것은 우리가 다시 쓴 학습 JSON뿐입니다.
